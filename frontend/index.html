AgriVision Deep Learning CNN Architecture

Convolutional Neural Network built with TensorFlow / Keras & trained on the PlantVillage Benchmark Dataset

Framework TensorFlow / Keras
Parameters 3,254,182
Benchmark Dataset PlantVillage (38 Classes)
Validation Accuracy 97.4% (Top-1)

Hierarchical Convolutional Feature Hierarchy

Input Layer
224 × 224 × 3

Normalized RGB leaf image tensor [0, 1]

Conv Block 1
32 Filters (3×3)

Edges, color gradients, leaf boundary contours

Conv Block 2
64 Filters (3×3)

Leaf venation, chlorophyll density, chlorosis

Conv Block 3
128 Filters (3×3)

Necrotic pustules, halo rings, early blight spots

Conv Block 4
256 Filters (3×3)

Complex multi-spot pathology & Grad-CAM layer

Softmax Head
38 Classes

GlobalAvgPool + Dense(512) + Softmax

Keras PlantVillage Dataset Specifications

54,305 Images

High-resolution botanical foliage images photographed under standardized agricultural conditions across healthy and infected crops.

14 Crop Species

Tomato, Potato, Corn (Maize), Apple, Grape, Peach, Bell Pepper, Strawberry, Cherry, Blueberry, Orange, Soybean, Squash, Raspberry.

Keras Augmentation

Real-time data augmentation pipeline with RandomFlip, RandomRotation(0.2), RandomZoom(0.15), and RandomContrast to prevent overfitting.

Grad-CAM Computer Vision

Visual explanation technique computing gradients flowing into the final convolutional layer (conv4_2) to generate class activation heatmaps.
